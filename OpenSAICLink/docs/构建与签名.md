# 构建与签名

标准 Gradle 工程，原生 Java/Views。工具固定为 AGP 9.2.1、Gradle 9.4.1、JDK 17、Android SDK 36；Wrapper 带官方 SHA-256 校验。

## 本机入口

运行 build-release.ps1，依次完成 Gradle 发布构建/Lint、纯 Java 离线回归、APK 身份和签名核验，并复制到 dist/。不会启动 ADB 或模拟器。

也可按顺序运行：

```powershell
./gradlew.bat :app:assembleRelease :app:lintRelease
python tests/run_offline.py
python tests/package_release.py
```

本机辅助脚本使用已有 E: 盘 JDK/SDK/Python；其他机器需调整路径和 local.properties。Gradle 用户目录、Android 工具用户目录和临时目录由脚本放在本工程内，避免新增全局依赖。

## 覆盖 E6 的签名

本机 .private/e6-signing.p12 和 .private/signing.properties 供发布构建使用，均已在 .gitignore 排除。源码归档也不包含这些文件。未来版本必须继续使用同一签名才能覆盖当前应用；不可让构建脚本静默生成另一把签名替代。

签名配置需要 storeFile、storePassword、keyAlias、keyPassword 四项。源码交接时由所有者单独保管/转移签名材料，不放到公开仓库、APK 或诊断包。

## 工程结构

- app/src/main：应用、原生界面、连接服务与 E6 核心。
- tests：离线协议/触控、配置迁移和会话检查，纯文本回归样本。
- docs：使用、验证和开发记录。
- dist：候选 APK 与构建凭据。

SessionController 为界面提供统一状态；SettingsStore/ConfigurationLogic 负责迁移与配置；HomeLayout 约束八个可编辑位置；LinkService 负责会话资源；原协议和坐标算法留在原有核心类中。


## 仓库中的新版工程

新版位于仓库 OpenSAICLink/ 子目录，E6 工程仍在仓库根目录。进入 OpenSAICLink/ 后构建。发布核验脚本会从父目录的 E6 APK 和 v0.6.0-e6 标签读取基准；独立本地工程则从同级 OpenSAICLink-Trial/ 读取。因此完整发布核验需要 Git 仓库历史及 E6 标签。
